BEATLINE ADMIN

Lägg till låtar

Låtarna skrivs direkt in i src/data/songs.ts på GitHub och blir en permanent del av spelet.

GitHub-anslutning

Använd en finmaskig GitHub-token med behörigheten Contents: Read and write endast för repot Manngez/Beatline. Token sparas bara i den här flikens session och följer inte med i någon commit.

Många låtar samtidigt

En fjärde kolumn på en rad kan åsidosätta standardkategorin.

Format: Titel | Artist | År | kategori. Kategorin är valfri och kan vara pop, rock, rap, swedish, svensk eller svenska.

Ingen ändring har gjorts ännu.

Vad som händer

Admin-sidan hämtar den senaste versionen av låtfilen, lägger varje låt i rätt hårdkodad lista och gör en enda commit. GitHub Pages kan därefter bygga om spelet från den nya koden.
